


### Definitions Recap
*   **Primary Key (PK):** The unique identifier chosen for the table.
*   **Candidate Key (CK):** A minimal set of attributes that uniquely identifies a row. (Any attribute or set of attributes with a `UNIQUE` or `PRIMARY KEY` constraint).
*   **Alternate Key (AK):** A candidate key that was *not* chosen to be the primary key.
*   **Super Key (SK):** A set of attributes that uniquely identifies a row. It is a superset of a Candidate Key (The CK itself, or the CK + any other column).
*   **Foreign Key (FK):** An attribute(s) that links to the Primary Key of another table.

### 1. Table: `departments`
*   **Primary Key (PK):** `{id}`
*   **Candidate Keys (CK):** `{id}`, `{department_name}`, `{department_no}`
*   **Alternate Keys (AK):** `{department_name}`, `{department_no}`
*   **Foreign Keys (FK):** None
*   **Super Keys (SK):** Any set containing `id`, `department_name`, or `department_no`.
    *   *Examples:* `{id}`, `{department_name}`, `{id, department_name}`, `{department_no, department_name}`, etc.

### 2. Table: `beds`
*   **Primary Key (PK):** `{id}`
*   **Candidate Keys (CK):** `{id}`, `{department_id, bed_no}`
*   **Alternate Keys (AK):** `{department_id, bed_no}`
*   **Foreign Keys (FK):** `{department_id}` references `departments(id)`
*   **Super Keys (SK):** Any set containing `{id}` or `{department_id, bed_no}`.
    *   *Examples:* `{id}`, `{department_id, bed_no}`, `{id, department_id}`, `{department_id, bed_no, id}`, etc.
